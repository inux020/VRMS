# Vehicle Rental Management System (VRMS)

## Overview
VRMS is a platform to manage vehicle rentals. It allows users to browse, book, and manage vehicles while providing admins the ability to manage fleet and bookings.

## Tech Stack
- **Backend:** Node.js
- **Database:** MongoDB
- **Frontend:** React

## Features
- User registration & authentication
- Vehicle browsing & booking
- Admin dashboard to manage vehicles & bookings
- Payment integration (optional)
